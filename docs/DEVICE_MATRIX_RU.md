По [Counterpoint, Q2 2026](https://counterpointresearch.com/en/insights/iphone-17-global-best-selling-smartphone-in-q2-2026), iPhone 17 лидировал в мировых продажах смартфонов (6%), а iPhone 17 Pro Max занимал второе место. Продажи используются как доступный ориентир популярности: они не равны доле активных устройств и не описывают аудиторию конкретного приложения.

[Apple](https://developer.apple.com/support/app-store/) сообщает, что на 7 июня 2026 года iOS 26 использовали 79% всех iPhone, взаимодействовавших с App Store. Эти данные подтверждают выбор поколения ОС, но не наиболее популярной подверcии 26.x. Для задания нет продуктовой аналитики по сочетаниям модели и ОС.

Каталог BrowserStack возвращает основные версии `26` и `17`. Он не подтверждает доступность именно 17.4. Локально проверяем 17.4; фактическую облачную подверсию следует сверять по сессии. Размер экрана меняем отдельным профилем, поэтому третья модель использует ту же основную ОС, что первая.

## Конфигурация и запуск

`config/device-matrix.ts` — единый список трёх облачных сочетаний. `config/wdio.browserstack.conf.ts` использует его при `IOS_MATRIX=true`. Все три сценария запускаются для каждой модели, всего девять сессий, последовательно (`maxInstances: 1`).

```sh
npm run test:matrix
```

Для одного устройства по-прежнему используется `npm test` с `IOS_DEVICE_NAME` и `IOS_PLATFORM_VERSION` в `.env`. Для одного сценария всей матрицы:

```sh
npm run test:matrix -- --spec tests/specs/screen-rotation.spec.ts
```

Локальные UDID привязаны к этому Mac, не переносимы на другой компьютер:

| Модель            | UDID выделенного симулятора          |
| ----------------- | ------------------------------------ |
| iPhone 17         | 4DC95AEA-4AC9-4672-AFA3-F61B0FD47292 |
| iPhone 15 Pro     | 3321CAFA-12CB-44BC-98A4-2F0203D05B12 |
| iPhone 17 Pro Max | 87735078-7993-423B-B9DE-BCB8821C2728 |

```sh
IOS_SIMULATOR_UDID=4DC95AEA-4AC9-4672-AFA3-F61B0FD47292 npm run test:simulator
```

Appium должен быть запущен через `npm run appium:local`, а путь `IOS_SIMULATOR_APP` заполнен в `.env`. Каждый локальный профиль запускается отдельно, без одновременного управления несколькими симуляторами. `fullReset` выключен. Создание симуляторов и локальный успех не подтверждают выполнение требования о реальных устройствах.

## Особенности первичной локальной подготовки

На новых симуляторах первый запуск WDA может занимать несколько минут. Для загрузки Simulator установлен отдельный `simulatorStartupTimeout=300000`, для создания всей сессии — `connectionRetryTimeout=600000`. Это не retries тестов и не увеличение ожиданий элементов.

На чистых iOS 17.4 и 26.5 наблюдалось системное окно `Search Engine Preference`. `AboutScreen` нажимает Continue только у этого конкретного окна. На iOS 26.5 также обнаружена подсказка `View Bookmarks, Share Menu and Open Tabs`, перекрывающая навигацию: она закрывается через кнопку внутри `TipView`. Неизвестные диалоги автоматически не принимаются.

Для выгрузки результатов конкретного облачного build после запуска:

```sh
node scripts/collect-browserstack-results.mjs finonex-ios-matrix-2026-10-23
```

Скрипт сохраняет `artifacts/browserstack-results.json` с устройствами, ОС, статусами и доступными ссылками на сессии/видео. Он использует локальный `.env` и не выводит ключ авторизации. Ссылки могут требовать входа в BrowserStack; доступность для проверяющего нужно подтвердить перед сдачей.

На iOS 17.4 адресная панель Safari в landscape имеет тип `XCUIElementTypeButton` с идентификатором `UnifiedTabBarItemView…`, а в portrait используется текстовое поле. Локатор поддерживает оба наблюдавшихся варианта.

Rotation на iOS 17.4 подтверждён 23 октября 2026 года (локальное время), сессия `e4ce8ddb-7c34-4440-89a8-66314de1f6fd`, 1 мин 34,7 с. В переходе между приложением и Safari сначала проверяется активный bundle ID: запрос дерева уходящего в фон приложения может зависать. Поиск системного диалога выполняется только в SpringBoard.
